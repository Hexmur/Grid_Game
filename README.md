# Grid_Game
A game inspired by the game Sol Cesto.

Grid_Game is a **Roguelike** retro and minimalistic game.
It's developed to be played directly inside the Linux terminal/shell.

---

## Key Feautures
**ASCII Interface**: Retro graphics created entirely using text characters and ANSI escape sequences.
**Command-Line Game**: Designed to run natively as a command-line game inside your terminal.

## Requirements
- Operating System: **Linux / macOS** (or WSL on Windows)
- Dependencies: `gcc`

## Installation & Execution

```bash
# 1. Clone the repository
git clone [https://github.com/your-username/Gird_Game.git](https://github.com/your-username/Grid_Game.git)

# 2. Navigate to the project directory
cd Grid_Game

# 3. Compile the game
gcc Grid.c -o GridGame

# 4. Run the game
./GridGame
